# Бот-ассистент

## Функционал
Telegram-бот, который обращается к API сервиса, анализирует ответ API и отправляет пользователю уведомление в Telegram.

## Стек
Python 3.9

## Команды для запуска проекта
Клонирование репозитория: git clone https://github.com/nazir710/homework_bot.git
Перейдите в директорию проекта: cd homework_bot
Cоздайте виртуальное окружение: python -m venv venv
Активируйте виртуальное окружение: source venv/Scripts/activate
Установите/обновите пакетный менеджер: python -m pip install --upgrade pip
Установите зависимости: pip install -r requirements.txt
Запуск скрипта: python homework.py
